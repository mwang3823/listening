# Tiếng Anh 10 - Unit 3: Music (Listening Interactive Player)

Trình phát âm thanh tương tác bài nghe **Unit 3: Music** (Trang 33 - Tiếng Anh 10 Global Success) thiết kế để nhúng trực tiếp vào **Canva Presentation**.

## 🎯 Tính năng
- **Bài 3 (Activity 3):** 5 thẻ câu hỏi True/False, mỗi câu 1 nút nghe riêng, phản hồi kết quả trực tiếp và dẫn chứng chi tiết.
- **Bài 2 (Activity 2):** 4 mục lựa chọn thông tin nghe được (Location, Guests, Decoration, Tickets) kèm nút nghe chứng minh.
- **Toàn bài:** Toàn bộ lời thoại phỏng vấn song ngữ Anh - Việt.
- **Chế độ Giáo viên:** Bật/tắt nhanh toàn bộ đáp án khi giảng dạy.
- **Điều khiển âm thanh:** Tua 3s, chỉnh tốc độ (0.8x, 1.0x, 1.2x), thanh tiến trình, âm lượng.

1. Vào **Settings** của repository trên GitHub $\rightarrow$ **Pages** $\rightarrow$ Chọn **Source: Deploy from a branch** $\rightarrow$ Chọn branch **`main`** / folder **`/ (root)`** $\rightarrow$ Nhấn **Save**.
2. Đường link web sẽ có dạng:  
   👉 `https://mwang3823.github.io/listening/`
3. Trong **Canva**: Chọn menu **Ứng dụng (Apps)** $\rightarrow$ Tìm **Nhúng (Embed)** $\rightarrow$ Dán đường link trên vào là xong!
